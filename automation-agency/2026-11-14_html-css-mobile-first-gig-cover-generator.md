# 🚀 TIL #004: สร้างปก Fastwork 2400×1600 ด้วย HTML/CSS + ระบบตรวจ Crop 3 มุมมอง & Mobile Readability

> **🎯 เป้าหมายของการบันทึกนี้:** บันทึกเทคนิคการสร้างภาพปกสินค้า/บริการด้วยโค้ด HTML/CSS ที่คุม Pixel, Safe Zone, และความอ่านง่ายบนมือถือได้แม่นยำกว่าการลากวางแบบเดิม

---

## 1. TL;DR — วันนี้ได้เรียน / ได้สร้างอะไร? (1–3 บรรทัด)
- **สิ่งที่สร้าง:** สร้าง **HTML/CSS Cover Generator** (`2400×1600px`) สำหรับ Gig #1 พร้อม **3-View Readability & Crop Inspector** เพื่อจำลองมุมมอง Desktop, การครอป 15% ซ้าย-ขวา, และ Thumbnail ขนาดเล็กบนมือถือก่อน Render เป็น PNG จริง
- **ทำไมเรื่องนี้ถึงสำคัญ:** รูปปกบนแพลตฟอร์ม Marketplace มักโดนครอปขอบเวลาแสดงเป็น Card และถูกดูบนจอมือถือเล็กๆ การเขียน Cover เป็นโค้ดพร้อม Preview 3 มุมมองช่วยให้แก้ Layout และขนาดฟอนต์ให้คมชัดได้ภายในไม่กี่วินาที

---

## 2. ปัญหาที่เจอ & วิธีลงมือแก้ (Problem → Build / Solution)
- **ปัญหาตั้งต้น (Pain Point / Bottleneck):**
  1. รูปปกขนาด `2400×1600` (อัตราส่วน 3:2) เมื่อไปแสดงในหน้าค้นหาหรือการ์ดบนมือถือ มักถูกครอปขอบซ้าย-ขวาออก ถ้าวางหัวข้อหรือ Mockup ชิดขอบ ข้อความจะแหว่งทันที
  2. ภาพที่ดูสวยเต็มตาบนจอคอม 27 นิ้ว พอหดเหลือขนาด Thumbnail มือถือ ตัวเลข KPI หรือการ์ดขั้นตอนเล็กๆ มักอ่านไม่ออก
  3. การปรับสีและแก้ข้อความในโปรแกรมกราฟิกทั่วไปทำซ้ำหรือคุม Pixel/Spacing ให้เป๊ะยากเมื่อต้องแก้หลายรอบ
- **แนวทาง/สถาปัตยกรรมที่เลือกใช้ (Code-as-Design + 3-View Verification):**
  - **15% Left/Right Safe Zone:** ล็อกขอบซ้าย-ขวาด้านละ `360px` (รวม 30%) เป็นพื้นที่กันครอป แล้ววางเนื้อหาและ Mockup ทั้งหมดไว้ใน **Center 70% Stage (`1680px`)** พร้อมโหมด `?guides=1` สำหรับเปิดเส้นประเช็ก Safe Zone
  - **Design Token Synchronization:** ใช้โทนสี Slate Tech & Emerald (`#0F172A`, `#10B981`, `#38BDF8`, `#06C755`) ชุดเดียวกับโค้ด `line_flex_lead_alert.json` เพื่อให้ภาพปกกับระบบจริงดูเป็นแบรนด์เดียวกัน
  - **Mobile Readability Polish (รอบตรวจแก้จริง):** หลัง Render ภาพแรกออกมาตรวจใน Preview 3 มุมมอง พบว่าข้อความย่อยและตัวเลข KPI บนจอมือถือยังเล็กเกินไป จึงปรับแก้ทันที:
    - ขยายการ์ด Step 01–03 (Title `49px`, Subtitle `#F1F5F9` `37px`, ขยายป้าย Step/ไอคอน/ลูกศร และเปลี่ยนไอคอน Google Sheets เป็นตารางสเปรดชีต)
    - เพิ่มคอนทราสต์ข้อความซ้ายบน + ขยาย 3 Feature Pills
    - ขยาย Mockup จอมือถือขึ้น `+15%`, ย่อความสูงแถวใน Tablet เพื่อให้ตัวเลข KPI (`48`, `< 1 วิ`, `+391%`) ใหญ่และอ่านออกทันทีโดยไม่ต้องซูม
    - ขยายป้าย `1s ส่งเข้า LINE อัตโนมัติ` ให้เด่นชัดใน Thumbnail เล็ก
